# TimescaleDB

TimescaleDB is a PostgreSQL extension for time-series data.
([source](../sources/2026-01-02-timescaledb-notes.md))

It is frequently compared with [InfluxDB](influxdb.md), which is not
covered in this bundle.

Storage is organised in [hypertables](../concepts/hypertable.md).
